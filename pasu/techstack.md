# Pasu - Tech Stack

The Pasu project is a Flask-based web application with AI integration, local Excel-based storage, and cloud sync capabilities. Below is a breakdown of the technologies and libraries used across the stack.

## Backend
- **Python**: Core programming language.
- **Flask**: Web framework used for routing, API endpoints, and rendering templates.
- **Werkzeug**: Used for secure file uploads (`secure_filename`).
- **OpenPyXL**: Data storage mechanism. Replaces a traditional relational database by storing records in an Excel workbook (`farmer_data.xlsx`).

## Frontend
- **HTML / CSS / JavaScript**: Standard web technologies utilizing Jinja2 templating from Flask.
- **Tailwind CSS**: Utility-first CSS framework for styling (loaded via CDN).
- **Chart.js**: Library for data visualization and analytics on the dashboard.
- **Leaflet.js**: Interactive mapping library for displaying outbreak or geospatial data.
- **Marked.js**: Markdown parser for rendering chat responses or AI outputs.
- **Google Fonts & Material Symbols**: Typography and icons (Hanken Grotesk, Manrope).

## AI & Machine Learning (RAG/NLP)
- **LangChain**: Orchestration framework for building the RAG (Retrieval-Augmented Generation) pipeline.
  - `langchain_community`, `langchain_classic`, `langchain_huggingface`, `langchain_groq`
- **FAISS (Facebook AI Similarity Search)**: Vector database used to index and search embeddings.
- **HuggingFace Embeddings**: Embedding model for converting text to vector representations.
- **Groq (ChatGroq)**: High-speed LLM inference endpoint used for the chatbot.
- **Google GenAI (Gemini)**: Used for calculating risks and generating AI-driven recommendations (`ai_rules.py`).

## Integrations & External Services
- **Google Drive API (`pydrive2`)**: Used for backing up and syncing local data to the cloud.
- **Twilio**: Used for sending SMS / WhatsApp notifications to farmers.
- **SMTP (`smtplib`)**: Used for dispatching email alerts (e.g., when an outbreak threshold is crossed).
- **Dotenv (`python-dotenv`)**: Environment variable management.

## Project Structure Highlights
- `/templates/`: Jinja2 HTML templates for farmer and vet dashboards, login, and chatbot views.
- `/uploads/`: Temporary or persistent local file uploads.
- `/faiss_index/`: Persisted FAISS vector store.
- `/graphify-out/`: Knowledge graph and system visualization generated by Graphify.
