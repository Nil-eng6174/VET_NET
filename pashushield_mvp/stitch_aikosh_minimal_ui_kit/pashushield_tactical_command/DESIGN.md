## Brand & Style

The design system establishes a high-stakes, emergency-grade operational command interface. Tailored for veterinary surveillance, field triage, and national biosecurity response, the aesthetic fuses the computational density of an emergency operations center with the raw visual clarity of tactical telemetry software. 

Drawing from brutalist information design and technical telemetry, the interface discards decorative softness in favor of structural discipline, pure right angles, zero border-radii, and hard monochromatic containment. The visual mood is urgent, authoritative, and unflinching. It commands immediate focus during biosecurity outbreaks while remaining usable in high-glare field environments, mobile triage vans, and dark central command bunkers.

Every screen communicates definitive situational awareness. Data cards, maps, and status streams do not float as decorative cards; they are precision modules locked into a structural grid, articulated with technical telemetry marks, rigid hairline borders, and vivid saffron alert signals.

## Colors

The palette operates under a high-contrast dark visual architecture, optimizing visibility across continuous 24/7 command operations. 

- **Primary (`#EA5B0C`)**: The saffron radar accent is reserved exclusively for primary interaction points, emergency callouts, active outbreak vectors, and high-priority states.
- **Secondary (`#131C2B`)**: Deep institutional slate navy, providing intermediate structural surfaces, headers, and container tiers that evoke sovereign tech platforms.
- **Tertiary (`#00E599`)**: Radar emerald acts as the vital operational indicator, signaling synchronized networks, valid diagnostics, offline-sync confirmation, and nominal biosurveillance nodes.
- **Neutral (`#080B10`)**: The deep operational dark background minimizes eye fatigue and maximizes contrast against high-density data visualizations.

Additional semantic tokens include `threat-crimson` (`#FF2A3B`) for confirmed mortality alerts, `telemetry-amber` (`#F59E0B`) for cluster suspect states, and `data-parchment` (`#F3EAD8`) as a specialized telemetry high-readability text token for critical metrics and tabular telemetry readouts.

## Typography

Typography pairs the structural geometry of **Space Grotesk** with the neutral precision of **Geist**.

- **Display & Headings (Space Grotesk)**: Chosen for its angular, technical character. Headings and telemetry metrics project military-grade efficiency and sovereign computing authority. Numerical outputs, cluster counts, and temporal indicators are tracked in uppercase tracking formats to convey status urgency.
- **Body & Content (Geist)**: Delivers dense diagnostic entries, lab assays, symptom breakdowns, and triage procedures with neutral clarity and compact vertical metrics.
- **Labels & Tags (Space Grotesk)**: Formatted with wide letter spacing and bold capitalization (`letterSpacing: 0.08em`), evoking technical status readouts, sensor tags, and GPS coordinates.

## Layout & Spacing

The layout model is anchored on an uninterrupted, zero-gap technical grid. Instead of floating padded components, panels are stacked against each other separated by `1px` high-contrast telemetry divider borders (`panel-gap`), mirroring cockpit instruments and surveillance dashboards.

### Grid & Density
- **Command Center Screens (Desktop)**: A 12-column rigid matrix with zero margins, 1px borders, and fixed 320px operational sidebars (collapsible to 64px icon strips). Layouts maximize situational awareness on 1080p and 4K displays.
- **Field PWA (Mobile)**: Single-column full-bleed layout. Touch targets maintain a mandatory 48px minimal bounding box despite the compact brutalist aesthetic.
- **Spatial Constraints**: Incident grouping cards and GIS map indicators explicitly encode the core algorithmic limits: `10 km` territorial radius tags and `48 hours` temporal counters are displayed on fixed 32px height telemetry bands across the top of analytical components.

## Elevation & Depth

This design system rejects conventional drop shadows and soft blurred elevations. Depth is established purely through **tonal stacking, luminance contrast, and 1px crisp borders**.

### Depth Layers
1. **Base Layer (`#040609` / `depth-void`)**: The deepest foundational backdrop, exposed only behind data tables, radar coordinate viewports, and primary viewport dividers.
2. **Panel Layer (`#080B10` / `surface-base`)**: Primary card and panel surface.
3. **Active/Focus Layer (`#0D131C` / `surface-panel`)**: Raised state for operational monitors, active telemetry streams, and open inspect drawers.
4. **Header/Interactive Layer (`#131C2B` / `surface-panel-active`)**: Used for persistent toolbars, table headers, and focused inputs.

### Telemetry Accents & Focus
- **Hairline Dividers**: Surfaces are delineated by crisp `1px solid #1E293B` outlines.
- **Active State Highlights**: Focus and active targets drop the border to a bright `1px solid #EA5B0C`, accented by a sharp 1px offset outer indicator (`outline: 1px solid #EA5B0C; outline-offset: 2px`).
- **Emergency Glow**: In cases of `Risk Level: HIGH` or active `Outbreak Risk`, cards receive a zero-blur, high-intensity perimeter line (`box-shadow: inset 0 0 0 1px #EA5B0C`).

## Shapes

The shape philosophy is strictly **brutalist and non-rounded** (`roundedness: 0`). 

Every element—including buttons, cards, modal dialogs, alert badges, and input inputs—terminates in razor-sharp 90-degree corners. 

To reinforce the technical and military surveillance identity:
- **Corner Notches**: Analytical cards feature optional corner chamfers (cut-corners) or registration crosshairs (`+`) rendered via pseudo-elements at terminal coordinate intersections.
- **Government Badge Stamp**: Official emblems and verification tokens use strict rectangular borders with internal keylines rather than oval or circular ribbons.

## Components

### Buttons
- **Primary Tactical**: Solid saffron (`#EA5B0C`) fill, pure black (`#040609`) bold uppercase `Space Grotesk` text, zero border-radius. Active state transitions to `#FF2A3B` with zero transition delay.
- **Secondary Telemetry**: Translucent navy background (`#0D131C`) with a `1px solid #334155` border and `#F3EAD8` text. Hover shifts border to `#EA5B0C`.
- **Destructive/Emergency**: Deep crimson background (`#FF2A3B`) with pure white bold text. Used for quarantine initiation or outbreak declaration.

### Data & Risk Badges (Chips)
- Sharp rectangular capsules, height fixed at 22px, font size 10px uppercase `Space Grotesk`.
- **Risk: HIGH**: `#FF2A3B` text on `#28070B` background with a `1px solid #FF2A3B` frame.
- **Watch / Suspected Cluster**: `#F59E0B` text on `#261A05` background with `1px solid #F59E0B` frame.
- **Operational / Normal**: `#00E599` text on `#022417` background with `1px solid #00E599` frame.

### Form Inputs & Checkboxes
- **Input Fields**: Background `#0D131C`, bottom border `2px solid #334155`, top/side borders `1px solid #1E293B`. Text input is `#FFFFFF` with monospaced numbers. Active focus triggers an `#EA5B0C` bottom boundary.
- **Checkboxes & Radios**: 16x16px sharp squares with a `1px solid #334155` border. Selected state is a solid `#EA5B0C` square core with a 2px inner void margin.

### Telemetry Cards & Metric Blocks
- Modular bounding boxes with header strips styled with `#131C2B` backgrounds.
- Header bars contain technical breadcrumbs, coordinate readouts (e.g., `LAT: 28.6139 | LNG: 77.2090`), and status dot indicators.
- Large quantitative readouts are set in `telemetry-num` typography using `#F3EAD8` (Parchment), flanked by delta tags indicating 48-hour changes.

### Inspection Table & Lab Chain of Custody
- Dense row height (36px desktop / 44px field touch).
- Column separators styled with subtle `1px solid #1E293B`.
- State columns reflect linear lab progression (`In Transit → Received → Result Pending → Resulted`) represented as a connected horizontal block diagram with sharp chevron dividers.
